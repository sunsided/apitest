# Documentation

- README files are rendered on crates.io, docs.rs and npm. Every link to a repo file and
  every image uses an absolute URL (`https://github.com/sunsided/apitest/...`). Only in-page
  anchors may be relative.
- `crates/apitest/README.md` runs as a doctest (`ReadmeDoctests` in `lib.rs`), so its `rust`
  blocks must compile and pass. Use `rust,no_run` or `rust,ignore` only with a stated reason.
- The workspace `README.md` is GitHub-only. Its Rust snippets are illustrative fragments and
  are not compiled; keep them consistent with the real API when the API changes.
- Code blocks are tagged with their language.
- Tables of contents between `<!-- START doctoc -->` markers are generated by doctoc. Do not
  edit them by hand.
- Keep badges, the License section and the MSRV statement consistent with `Cargo.toml`.
